# AI Phone Optimizer — PWA starter

## Что это
Устанавливаемое с веб-сайта PWA-приложение с профилями рекомендаций, чек-листами и локальным сохранением выбранного режима.

## Важно
- Это не нативное iOS-приложение и не измеритель температуры/здоровья батареи.
- iOS Safari не предоставляет веб-приложениям доступ к температуре аккумулятора, частотам CPU/GPU, реальной максимальной ёмкости батареи или управлению системными настройками.
- Для установки на главный экран сайт должен быть размещён по HTTPS. Открытие локального HTML-файла не даёт полноценную PWA-установку.

## Размещение
Загрузите все файлы этой папки на статический HTTPS-хостинг (например, GitHub Pages или Netlify). Не меняйте относительные пути файлов.

## Установка на iPhone
1. Откройте опубликованный HTTPS-адрес в Safari.
2. Нажмите «Поделиться».
3. Выберите «На экран Домой».
4. При необходимости включите «Открывать как веб-приложение».
5. Нажмите «Добавить».

После первой загрузки приложение сможет открываться офлайн благодаря service worker.
