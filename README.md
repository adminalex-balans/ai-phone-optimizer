# AI Phone Optimizer v3 (PWA)

Одна кнопка «Сканировать»: приложение замеряет, что доступно сайту (частота кадров, скорость процессора, падение скорости под нагрузкой, уменьшение движения/прозрачности), затем выдаёт приоритетный список настроек iOS: что выключить или включить, с путём и коротким объяснением.

## Ограничения iOS
Ни сайт, ни обычное приложение iOS не могут читать чужие настройки, температуру, расход по приложениям и открывать Настройки на нужном пункте. Поэтому часть пунктов даётся как проверенный экспертный список с путём.

## Обновление
Замени файлы в репозитории GitHub (Add file → Upload files), дождись публикации GitHub Pages и открой приложение дважды.
